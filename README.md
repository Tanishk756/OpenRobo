# OpenRobo

Open-source robotics commons: discover, build, simulate, deploy, and contribute.

## Status
Foundation / architecture phase.

## Core principles
- Free to use
- Open source
- Vendor neutral
- Hardware agnostic
- AI/model agnostic
- All robotics domains
- Local-first
- License-aware
- Reproducible
- Community driven
