# OpenRobo Resource Metadata Standard

Every resource should be representable by a machine-readable manifest.

Minimum conceptual fields:
- id
- name
- version
- resource type
- source
- documentation
- license / SPDX
- maintainer
- robotics domains
- capabilities
- platforms
- architectures
- runtimes
- dependencies
- hardware requirements
- interfaces/protocols
- simulation support
- status/maintenance
- provenance
- security/SBOM references

The schema must be versioned and backward compatible where practical.
