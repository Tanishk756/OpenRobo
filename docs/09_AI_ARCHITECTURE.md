# AI Architecture

OpenRobo AI must be model/provider agnostic.

Supported conceptual backends:
- hosted APIs
- self-hosted open models
- local models
- no-AI mode

AI capabilities:
- semantic discovery
- resource summarization
- compatibility reasoning
- stack recommendations
- documentation assistance
- troubleshooting
- robotics knowledge RAG

AI recommendations must cite the underlying resource metadata/evidence and clearly distinguish facts from inference.
