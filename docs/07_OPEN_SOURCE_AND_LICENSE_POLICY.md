# Open Source and License Policy

OpenRobo does not claim ownership of upstream projects.

For every indexed resource:
- preserve upstream attribution
- record authoritative license information
- retain required notices
- record source provenance
- avoid implying endorsement
- distinguish metadata from copied source code
- flag license incompatibilities
- never remove upstream copyright notices

License analysis is informational and does not replace professional legal advice.

The final license for OpenRobo's own code will be selected after a dedicated compatibility review.
