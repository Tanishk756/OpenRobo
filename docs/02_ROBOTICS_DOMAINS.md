# Robotics Domains

The taxonomy is extensible and must support at minimum:

- UAV / multirotor / fixed-wing / VTOL
- UGV / rover / AGV / AMR
- USV / surface robotics
- AUV / ROV / underwater robotics
- Robotic arms / manipulators / grippers
- Mobile manipulators
- Humanoids / bipedal systems
- Quadrupeds / legged systems
- Industrial robotics / cobots
- Logistics / warehouse robotics
- Inspection robotics
- Agricultural robotics
- Medical / assistive / rehabilitation robotics
- Space / planetary robotics
- Swarm / multi-agent robotics
- Research / experimental robotics

New domains must be addable through metadata rather than core-code changes.
