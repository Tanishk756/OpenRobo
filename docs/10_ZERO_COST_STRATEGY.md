# Zero-Cost Development Strategy

Goal: enable development and early public operation with minimal or zero recurring cost.

Principles:
- use open-source software
- use free developer tooling and CI where available
- rely on upstream repositories instead of unnecessary mirroring
- avoid mandatory cloud compute
- avoid mandatory AI APIs
- local-first CLI and workflows
- cache only what is operationally necessary
- keep large simulation workloads local by default

Scaling infrastructure may eventually require funding. The user-facing core should remain free.
